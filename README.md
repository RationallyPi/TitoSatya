This project is about comparing the different narratives and biases present in the Nepali english newspapers on the subject of the present prime minister Balen and the previous prime minister KP Oli. The project is divided into 3 main phases.

1. Data scraping phase
-> In this phase, I'll focus on gathering all the digital copies of relevant nepali english newspapers, and scrape relevant news. The scraping will be done from the start of Balen's tenure to 1 month since he assumed office, similar will be done for the last tenure of KP Oli
   
3. Data cleaning
-> Data gathered from OCR through all the newspapers will be cleaned and only relevant articles will be collected in the dataset.
   
5. VADER Processing
-> Using VADER architecture, sentimental analysis of the collected dataset will be done.

-?After receiving all the results a aggregated summary relating the total bias/sentiment of the articles published in the Nepali newspapers will be made.
